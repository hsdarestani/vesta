# Vesta

Mobile-first Persian self-care PWA for daily routines, cycle-aware care, progress, challenges and contextual Vesta commerce.

## MVP screens
- Today / daily routine
- Smart routines & product cabinet
- Cycle calendar & mood check-in
- Weekly progress / Glow Score
- Challenges
- Personalized shop

## Local run
Serve the repository root with any static HTTP server.

## Deploy
Pushes to `main` deploy automatically to `vesta.smarbiz.sbs` through `.github/workflows/deploy.yml` using repository secrets `HOST` and `PASS`.
